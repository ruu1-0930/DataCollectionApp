# 跌倒检测可行性调研报告（与现有鞋垫系统集成）

> 生成：2026-06-28　范围：**仅调研对比**，不实现功能。
> 硬件前提：双足蓝牙智能鞋垫，每脚 9 路足底压力（ADC 0–4093）+ 6 轴 IMU（`ax,ay,az,gx,gy,gz`）；BLE 帧式上传，**采样约几 Hz（非高频）**；数据进 Flask/MySQL，已有 IMU→T1–T5 的 SVM。

---

## 0. 结论速览

**当前几 Hz 的 BLE 采样率下，跌倒检测无法可靠落地——瓶颈是采样率而非算法。** 冲击/失重瞬态只持续数十毫秒，几 Hz 会直接混叠/漏采。要落地必须先改固件：IMU 采样升到 **≥20 Hz（目标 50 Hz）**，并采用「端上阈值触发 + 事件窗口上传」。足部位置对跌倒检测次优（文献多用腰/胸），但**9 路足底压力是本系统差异化优势**，可做 IMU+压力融合。预冲击保护（落地前触发气囊等）需 >130ms 提前量 + 高采样 + 低延迟 BLE，**超出本系统范围**。

---

## 1. 跌倒检测方案分类

| 方案 | 原理 | 优点 | 缺点 |
|---|---|---|---|
| **阈值法** | 三相模式：失重(加速度合矢量 SVM→~0g) → 冲击(尖峰 ~3.0–3.5g) → 静止；陀螺角速度阈 ~47°/s | 计算极轻、可端上跑、无需训练 | 误报高（坐下、跳跃）、对佩戴位置敏感 |
| **经典 ML**（SVM/RF/kNN/决策树） | 窗口手工特征（SVM 幅值、均值/方差、jerk、峰值、能量） | 精度优于固定阈值、数据需求适中、契合现有 SVM 管线 | 需特征工程、对未见跌倒类型鲁棒性弱 |
| **深度学习**（CNN/LSTM/CNN-LSTM/Transformer） | 原始 IMU 窗口端到端 | CNN-LSTM≈98.9%，低采样率下更稳 | 需大量标注 + 服务端算力 |
| **预冲击检测** | 检测落地前的失重/姿态突变 | 可触发保护 | 需 >130ms 提前量 + 高采样，**本系统不适用** |

典型阈值（文献）：失重下阈 ~0.6–0.9g；冲击上阈 ~3.0–3.52g；陀螺 ~47.3°/s；躯干倾角 ~24.7°。

## 2. 传感器位置与适用性

- 跌倒检测文献多把 IMU 装在**腰/胸**（接近质心，腰部准确率可达 ~98%）；**四肢/足部一般不推荐**——足部摆动期有大幅周期性加速度，会掩盖跌倒特征，且足部运动不代表整体质心轨迹。
- **足底压力可补足 IMU 看不到的足地失稳**：跌倒时表现为压力突失/异常重分布。鞋垫与斜坡研究表明 IMU+压力融合优于单 IMU。本系统 9 点位可用，但低于部分研究建议的 ~15 区覆盖。

## 3. 采样率要求（决定性）

- 文献最低门槛：**~20 Hz 基本够用**，CNN-LSTM 可低至 ~20 Hz（98.9%），10 Hz 是 DL 实用下限；50 Hz 推荐。
- **几 Hz 远低于下限**，冲击瞬态会被混叠/漏采，事后与预冲击检测均不可靠。
- 实用目标：**事后检测 ≥20 Hz；预冲击/保护 ≥50 Hz**。

## 4. 公开数据集

| 数据集 | 位置 | 采样率 | 备注 |
|---|---|---|---|
| SisFall | 腰 | 200 Hz | 2 加速度计 + 陀螺，规模最大 |
| MobiFall | 大腿口袋(手机) | ~87/200 Hz | |
| UMAFall | 踝/腰/腕/胸/大腿 | ~20 Hz | 多位置，**含踝节点最接近足部** |
| UP-Fall | 多体部 + 视觉 | ~18 Hz | 多模态 |
| KFall | 下背 | 100 Hz | 含预冲击标注 |
| FARSEEING | 下背/大腿 | ~20–100 Hz | 真实世界跌倒，访问受限 |

**无足底压力跌倒公开数据集**；UMAFall 的踝节点最接近。本系统若推进，需**自采足底压力+IMU 跌倒数据**。

## 5. 集成可行性结论与路线

- **现状（不改固件）**：仅能做粗糙的「事后静止」启发式，**不建议作为安全功能**。
- **改造路径**：
  1. 固件 IMU 采样升至 **≥20 Hz（目标 50 Hz）**；
  2. **端上阈值触发 + 事件窗口上传**——MCU 上跑轻量阈值器高频检测，命中候选事件才把窗口数据突发上传，避免持续高速 BLE 与功耗；
  3. 服务端用**阈值触发 + 经典 ML/CNN-LSTM**，融合 IMU 与足底压力丢失信号，**复用现有 SVM/Flask 栈**。
- **诚实的局限**：足部位置次优于腰部；9 点位低于建议覆盖；无现成足底压力跌倒数据集，需自采。足底压力是差异化卖点，应做 IMU+压力融合而非单 IMU。

## 6. 临床阈值参考（与步态分析共用，供肌少症筛查）

跌倒风险与步态变异性强相关，可与步态分析模块共用：步时变异 CV%（年轻 ~1.1%、老年非跌倒者 ~1.7%、跌倒者 ~5.3%，CV% 是单项最佳前瞻预测指标）；左右不对称 >10% 告警。
